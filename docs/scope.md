# v0.1 scope and evidence boundary

The project evaluates offline replay of camera frames under controlled transport faults. Results are software-in-the-loop evidence for a specific WSL2 GPU machine and pinned dependency set.

Excluded from v0.1: real vehicle and CAN/Panda validation, HIL, real-time guarantees, DRIVE AGX/DriveOS, Hyundai production equivalence, and CARLA closed-loop performance claims.
